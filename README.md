# 🪐 3D Interactive Solar System & Exoplanet Planetarium (Three.js / WebGL)

An interactive **3D Solar System Planetarium Explorer** built with **Three.js (WebGL 2.0)**, Tailwind CSS, and ES6 JavaScript — featuring realistic planetary orbits, glowing starfields, real-time orbital speed sliders, and smooth 360° camera controls.

👉 **[Launch Live Interactive 3D Planetarium](https://newtechportal.com/projects/3d-solar-system-planetarium-explorer/preview)**  
📦 **[Download Complete Source Code (.ZIP) & Docs](https://newtechportal.com/projects/3d-solar-system-planetarium-explorer)**

---

## ✨ Key Features
- **Real-Time 3D Orbital Simulation:** Animated planets revolving around a glowing sun with smooth 60 FPS WebGL rendering.
- **Interactive Camera & Speed Controls:** Drag to orbit 360°, scroll to zoom, and adjust orbital time speed dynamically.
- **Zero-Build Architecture:** Pure HTML5, Tailwind CSS, and ES6 JavaScript — runs directly in any modern browser without npm build steps.
- **Desktop & Mobile Touch Ready:** Fully responsive viewport with smooth touch/mouse navigation.

## 🚀 Quick Start (Local Setup)
1. Download the full `.ZIP` source package from **[TechPortal](https://newtechportal.com/projects/3d-solar-system-planetarium-explorer)**.
